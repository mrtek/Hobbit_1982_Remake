Современный кроссплатформенный ремейк легендарной текстово-графической адвенчуры **«Хоббит» (The Hobbit)** 1982 года от *Melbourne House* (авторы оригинала: **Philip Mitchell** и **Veronika Megler**), воссозданный на движке **Godot 4.3+**.

---

## ✨ Ключевые особенности

### 🎭 Три аутентичных режима игры
Вы можете в любой момент выбрать или сменить режим оформления и звучания:

1. **🌟 Современный (Modern Edition)**
   - Детализированная графика высокого разрешения для всех 79 локаций.
   - Живая оркестровая музыка и кинематографическая вступительная заставка.
   - Атмосферная типографика шрифта *Greengoth*.
2. **💾 Ретро (VGA Edition)**
   - Винтажный пиксель-арт стиль MS-DOS конца 1980-х.
   - Классический саундтрек AdLib / Sound Blaster.
   - Аутентичный системный шрифт DOS 8x16 (*dos2000*).
3. **🕹️ Классический (ZX Spectrum Edition)**
   - Оригинальная 8-битная графика 1982 года.
   - Легендарный чиптюн **Neil Brennan** (версия Commodore 64 SID).
   - Классический растровый шрифт ZX Spectrum и ностальгическая заставка загрузки с ленты.

---

### 🧠 Умный парсер и живой мир (WorldSim)
- **Двуязычный парсер естественного языка (Inglish)**: понимает команды на русском и английском языках (осмотр, направления, взаимодействие с контейнерами, обращение к персонажам).
- **Автономный мир (WorldSim)**: Гэндальф, Торин, Бард, Элронд, Голлум и другие NPC живут своей жизнью — свободно перемещаются во времени и пространстве, взаимодействуют с окружением, подбирают предметы и реагируют на просьбы Бильбо.
- **Интерактивные механики**: открывающиеся сундуки, шкафы, бочки, закрытые двери (дверь Прихожей Бэг Энда), окаменение троллей на рассвете, битва за Эребор и финальный триумф при доставке Аркенстона.

---

### 🎮 Современный и удобный интерфейс
- **Гибридное управление**: классическая строка ввода команд + интерактивный компас (С, Ю, З, В, СВ, СЗ, ЮВ, ЮЗ, Вверх, Вниз) + панель быстрых действий (Осмотреть, Инвентарь, Ждать, Взять всё, Сохранить, Загрузить).
- **Система сохранений (Ren'Py Style)**: 6 независимых слотов сохранения с автоматическими скриншотами локации, временными метками, режимом игры и корзиной для безопасного удаления с диалогом подтверждения.
- **Динамическая музыка**: 18 музыкальных тем с бесшовным плавным затуханием (fade-out/fade-in) при смене локаций и сюжетных событий.
- **Кинематографический экран «Об игре»**: плавно бегущие снизу вверх титры с историей создания игры, ускорением по зажатию Пробела, поддержкой ручной прокрутки колесиком мыши / стрелками и процедурным шейдером мягких рваных краев для меняющихся иллюстраций.

## 🚀 Как запустить и открыть проект в Godot

### Требования
- **Godot Engine 4.3 или новее** (Standard версия, без .NET).

### Шаги установки:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mrtek/Hobbit_1982_Remake.git
   ```
2. Откройте **Godot Engine**.
3. Нажмите кнопку **«Импорт» (Import)** в менеджере проектов.
4. Выберите файл `project.godot` в корне склонированной папки.
5. Нажмите **«Импортировать и редактировать» (Import & Edit)**.
6. Нажмите клавишу **F5** (или кнопку «Запустить проект» в правом верхнем углу редактора).

## 📂 Структура проекта

```
├── project.godot            # Главный конфигурационный файл проекта Godot
├── export_presets.cfg       # Пресеты сборки и фильтры экспорта (Windows Desktop)
├── assets/
│   ├── fonts/               # Шрифты для каждого режима (MODERN, DOS, ZX)
│   ├── images/              # Графика локаций, заставки, иконки UI и credits
│   ├── music/               # 18 саундтреков (Modern, VGA SoundBlaster, ZX SID)
│   └── shaders/             # Процедурные шейдеры (маска титров с рваными краями)
├── data/
│   ├── dictionary.json      # Словарь парсера (глаголы, направления, имена)
│   ├── npcs.json            # Характеристики и стартовые позиции 17 персонажей
│   ├── original_locations.json # Описания 79 комнат, выходы и связи
│   ├── original_objects.json   # Свойства 43 предметов (масса, контейнеры, ключи)
│   └── music_triggers.json  # Триггеры динамической смены музыки
├── scenes/
│   ├── main.tscn            # Главная сцена игры, UI и экраны
│   ├── save_load_screen.tscn# Модальное окно сохранений в стиле визуальных новелл
│   └── credits_screen.tscn  # Кинематографический экран титров
├── scripts/
│   ├── main.gd              # Логика интерфейса, заставок и переключения режимов
│   ├── game_state.gd        # Ядро состояния игры, инвентарь, правила и сохранения
│   ├── parser.gd            # Парсер естественного языка Inglish (RU / EN)
│   ├── world_sim.gd         # Симуляция автономных действий персонажей
│   ├── audio_manager.gd     # Менеджер динамической музыки и плавных переходов
│   ├── save_load_screen.gd  # Логика модального меню слотов сохранения
│   ├── credits_screen.gd    # Логика бегущих титров и шейдерного показа картинок
│   └── test_runner.gd       # Встроенный автоматический тестовый раннер (25 тестов)
├── WORK_LOG.md              # Подробный технический лог всех этапов разработки
└── README.md                # Документация проекта
```

## 🧪 Автоматическое тестирование

В проект встроен автоматический раннер тестов, проверяющий базу данных, симуляцию, парсер, графику всех 3 режимов, музыку, сохранения и титры:

```bash
godot --headless -s res://scripts/test_runner.gd
```
*Все 25 интеграционных проверок проходят со статусом PASS.*
